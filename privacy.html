Privacy Policy

Last updated: 15 September 2026

Scope

This application is operated by a single individual for managing their own YouTube channel. It has no other users.

Data accessed

With the operator's authorisation, the application accesses the operator's own YouTube channel data via the YouTube Data API and YouTube Analytics API: channel metadata, video metadata, and aggregate performance statistics. It uploads videos created by the operator to that same channel.

Storage and sharing

All data is stored locally on the operator's own machine. No data is transmitted to any third party, sold, or used for advertising.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The operator may revoke this application's access at any time via Google Account permissions.
