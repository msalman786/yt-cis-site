<h2>Scope</h2>

<p>This application is operated by a single individual for managing their

own YouTube channel. It has no other users.</p>


<h2>Data accessed</h2>

<p>With the operator's authorisation, the application accesses the operator's

own YouTube channel data via the YouTube Data API and YouTube Analytics API:

channel metadata, video metadata, and aggregate performance statistics. It

uploads videos created by the operator to that same channel.</p>

<p>All data is stored locally on the operator's own machine. No data is

transmitted to any third party, sold, or used for advertising.</p>
